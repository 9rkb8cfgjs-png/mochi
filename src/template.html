12. 关于更新和bug修复：其实灵感是有的，就是修改和修设备bug要花的时间太多，所以会比较慢，这点确实很力竭。网站一直有部署更新，跟我反馈的每个问题都修了，但是否修好只能用自己的设备验证，我没有设备，无法验证修复程度。反馈问题后都可以晚点刷新到新版试试（消息太多，反馈的问题修完后不会一一回复已修，可以晚一些刷新新版本后再试）。另外开屏是无法跳过的，只能等加载完后点击进入

mochi原版功能介绍
Mochi 字卡传讯
基于「星言字卡」修改的简约版情侣聊天模拟器，极简黑白灰设计，数据全部保存在本地，无需联网。所有内容均为代码触发、按概率运行，联系方可主动发送聊天消息。
聊天传讯
字卡交流：文字、情绪、心意、交流意图四种字卡回复，联系人所有内容均为字卡回复
每条消息使用多字卡回复：可开启、调触发概率与最少/最多条数
联系人发送的消息可额外触发聊天情绪字卡（情绪 / 心意 / 交流意图）
撤回与补发、已读不回、拍一拍、颜文字附加
聊天可同时发送图文消息（表情包或上传图片）
聊天可引用消息，引用可发送表情包 + 文字
联系人可随机收藏我发送的消息；我也可以收藏联系方发送的消息
主动发送：TA 会主动找你，可调概率、间隔与免打扰
聊天里点击顶部栏联系人的头像可打开【查岗 TA 的日常】页面
聊天页面点击顶部栏联系人的昵称，可以让对方立即发送消息
可搜索聊天记录并跳转到对应位置
聊天 + 按钮展开更多功能面板：帮我决定、邀请 TA、问问 TA、搜索记录、通话、拍一拍、头像互动、占卜
更多功能面板「TA 的提问」：让 TA 现在问一次（询问 / 小问题 / 好奇 / 吐槽）
字卡系统
字卡库：浏览全部字卡，支持搜索与自定义分组管理
聊天字卡分类可上传：【主字卡】【颜文字】【emoji】【表情包】【图片】【拍一拍】【语音】分类
互动卡片可自定义内容，概率触发互动（在字卡库里）
TA 的询问 / TA 的小问题 / TA 的好奇 / TA 的吐槽：内容可自定义
查岗日常字卡：地点、在做什么、说的话，均可自定义
情绪回复：按你当前的心情自动匹配相应字卡
字卡库页入口：自定义聊天字卡、查岗日常字卡、桌面今日情话、聊天默认字卡、聊天情绪字卡、聊天回应字卡、TA 的询问 / 小问题 / 好奇 / 吐槽
字卡管理：去重复、导出数据、一键清空所有分类
兼容导入 milk 字卡库导出的 json
系统预设字卡可逐句开关（桌面今日情话 / 聊天默认字卡）
互动卡片
联系人发送互动卡片：概率触发弹窗，或直接在聊天发送卡片
我发送互动卡片与联系人互动（邀请 TA / 问问 TA 在聊天内发送卡片）
可使用【帮我决定】提问联系人（功能参考：小红书@FelixFelicis 9416318007）
联系人邀请一起播放音乐
手机桌面
桌面多页滑动，可上传壁纸、自定义功能图标（默认空白需自己装修）
时钟、日历、备忘录、今日心情、离周末还有几天
桌面组件【今日情话】为联系人每日随机刷新想对你说的话（可在字卡库自定义添加）
桌面组件【今日备忘】可简单输入记录；【今日心情】可简单输入记录
和 TA 一起摸鱼打卡，桌面组件可统计摸鱼打卡天数
打开 mochi 使用时，我的摸鱼值和联系人的摸鱼值都会随机增加；桌面组件右侧黑色按钮可主动点击 +1
桌面【工作值】刷新机制与摸鱼值一致（双方随机增加）
桌面多页滑动（scroll-snap），指示器圆点点击切换，支持动态新增 / 删除最后一页（最多 5 页）
装修模式：点图标换图、点卡片设背景、添加卡片、恢复图标、完成
桌面图片组件（尺寸档位：小 / 中 / 大，全屏查看器）
第一页功能图标：聊天、主页、信箱、朋友圈、日历、纪念、占卜、收藏
第二页功能图标：聊天统计、提问记录、查岗、今日备忘、今天的心情、本周日常、离周末还有几天
桌面美化：深色模式、主题色、桌面字号、卡片大小、内置壁纸预设
小组件颜色：背景 / 边框 / 按钮 / 按钮文字 / 爱心外框颜色、小组件透明度、图标圆角
查岗
桌面【查岗】包含：TA 的日常、TA 在哪里、TA 在做什么、TA 想对你说——为【TA 的日常】字卡库内容随机刷新，可自由添加字卡
联系人更新日常时，聊天消息里会发送一条【联系人昵称 更新了一条日常】，且有概率触发联系人提醒你查岗的消息
音乐
音乐功能可本地上传音乐，也可链接上传网易云免费歌曲
桌面组件与【音乐】功能同步显示播放状态
联系人可主动更换音乐播放模式（循环播放 / 顺序播放 / 随机播放）
我的收藏、批量管理、悬浮小框可拖动
歌单：可新建歌单管理
听歌记录：联系人邀请听歌记录
自定义歌曲封面（上传图片压缩）、批量导入歌曲
通话
联系人可主动拨打和挂断电话；我也可以拨打
TA 会来电，可接听 / 拒绝，挂断后变为迷你小框
来电可播放自定义铃声（音效设置）
通话设置页：可调来电 / 接听 / 忙线 / 拒接 / 通话中挂断概率
通话背景图片：可上传 / 移除
信箱
信箱里我可以主动给联系人写信和回信
联系人可以主动写信和回信
新来信标记、回信确认等概率在回复设置-信箱可调
信件内容类型：颜文字 / emoji / 表情包 / 图片（多选上传压缩）
信件数据管理：导出 / 导入 / 清空所有信件
朋友圈
朋友圈里我可以主动发布朋友圈动态（点右上角 + 图标）
联系人可主动发布朋友圈
联系人可评论、回复我的朋友圈，我也可以评论、回复
点击动态头像可查看我的 / 联系人的全部朋友圈
点赞、评论、通知提醒（未读数字角标）
可删除单条动态（我的与 TA 的均可删）
可删除全部动态（分类删除：只删我的 / 只删联系人的 / 全部删除）
多联系人：朋友圈为全局共享，按联系人聚合显示
日历
每日首次打开，联系人会在日历留言并触发弹窗
日历里除了联系人留言，我也可以简单留言
日历可切换月份查看
今日心情卡片（心情图标 + 分类标签）
TA 正在做什么、TA 的留言卡片、我的留言卡片（可编辑留言）
纪念
桌面【纪念】可设置纪念日和倒数日
恋爱纪念日显示在桌面顶部双方头像下方（我们在一起的天数）
下一个纪念日倒计时
记录统计
桌面【提问记录】统计历史：提问记录、TA 的询问、TA 的小问题、TA 的好奇、TA 的吐槽、我的邀请 / 问问
桌面【主页】统计以下历史：联系人今日情话、联系人换头像、通话记录、每日摸鱼值、我的今日备忘、我的今天的心情
桌面【聊天统计】统计：相处记录（第一次聊天时间、最近聊天时间、聊天消息条数、文字数量、收藏记录）、聊天记录（消息比例、最常聊天时间段、最常聊天日期、平均每日消息、最长连续聊天、单日最高消息）、情绪表达（文字字卡 / 情绪 / 心意 / 交流意图使用次数排行）
占卜记录、帮我决定记录
个性化
